# Steam Deck Travel Comfort

This context defines the user-facing concepts for a Steam Deck plugin intended to reduce kinetosis during travel.

## Language

**Kinetosis Reduction**:
The intended user outcome: reducing travel-related motion sickness symptoms through a stable visual reference, without promising guaranteed prevention or a medical cure.
_Avoid_: Kinetosis prevention, motion sickness cure

**Stable Visual Reference**:
A persistent on-screen visual cue that represents the user’s level horizon and remains steady while the surrounding game view moves.
_Avoid_: Horizon overlay

**Virtual Horizon**:
A user-centered stable visual reference for level orientation in the real world, estimated from the Steam Deck’s device motion rather than the game’s camera or world orientation.
_Avoid_: Sensor-derived reference, world horizon, game horizon, camera horizon

**Artificial Horizon**:
A visual representation of the virtual horizon using a horizon line, evenly spaced dots across that line, and a transparent lower field suggesting the space below the horizon.
_Avoid_: Aircraft HUD, game HUD
