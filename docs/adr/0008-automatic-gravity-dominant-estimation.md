# Use Automatic Gravity-Dominant Estimation

The plugin will automatically estimate the virtual horizon from gravity-dominant device motion rather than require user calibration. This best matches the desired Kinestop-like experience and removes setup during travel, while requiring safeguards for acceleration, braking, and sustained turns.

The product goal is kinetosis reduction. Kinetosis prevention may be an aspiration, but the plugin must not imply guaranteed medical prevention. The virtual horizon remains world-level when the user reclines or intentionally changes the Deck’s holding angle; it does not silently recenter to the new viewing angle.
