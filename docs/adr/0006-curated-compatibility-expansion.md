# Start Curated, Expand Toward All Games

The plugin will launch with a curated list of verified Steam Deck games while treating broad Steam game support as the target. This makes compatibility claims honest during validation without narrowing the long-term product goal.

## Considered Options

Claiming support for all Steam games at launch was rejected because overlay behavior can differ across fullscreen, Vulkan, Proton, and gamescope modes. A permanently narrow scope was rejected because the intended value is broad travel use across the Steam library.
