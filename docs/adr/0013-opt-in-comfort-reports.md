# Collect Opt-In Anonymous Comfort Reports

The plugin will offer optional anonymous structured reports about user comfort and kinetosis reduction. Reports will never be required for continued use, preserving user control while providing evidence for tuning and evaluation. Each report will contain a minimal before/after comfort rating and an optional free-form comment.

## Considered Options

Local-only notes were rejected because they cannot provide aggregate evidence for tuning. Required reporting was rejected because a comfort feature should not depend on data submission. Detailed session data was deferred to avoid collecting more information than the initial evaluation needs.
