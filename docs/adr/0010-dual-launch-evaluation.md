# Require Technical and User Validation

The first broad release requires both technical evaluation of horizon stability and lag and early user reports of kinetosis reduction. Neither sensor metrics nor subjective comfort alone is sufficient evidence that the plugin works as intended.

The plugin will show a concise one-time notice that it aims to reduce kinetosis and does not guarantee prevention. The limitation remains accessible in the Decky plugin panel without persistent gameplay warnings.

## Considered Options

Technical metrics alone were rejected because stable, low-lag rendering does not establish user benefit. A limited pilot before collecting reports was rejected because the user wants both forms of evidence before release. Omitting the notice was rejected because the product must not imply a guaranteed health outcome; a persistent warning was rejected because it would add unnecessary gameplay clutter.
